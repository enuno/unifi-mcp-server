## Discovery packages and stop rules

- SD-WAN: authorized feature-enabled Site Manager account with read-only key; sanitized list/detail/status envelopes including empty, null, 401/403/404/429 and unknown fields; compare complete URL, type and all nested policy-related structures. Never use local Traffic Routes as Site Manager policy parity or restore removed Traffic Route writes. Policy mutation requires a separate published endpoint/payload and security review.
- Capture (console and AP): identify exact controller/AP model, Network/firmware release, UI workflow, permissions and sanitized request/response metadata. Record start/status/stop/download/cleanup job lifecycle, radio/interface/filter selection, packet/byte/duration/concurrency/storage limits, timeout/cancel/recovery/retention. Initiation is mutating and privacy-sensitive regardless of verb; no raw PCAP, key or HAR in git. A synthetic fixture is not endpoint proof. Obtain target/artifact-destination approval before even a discovery capture.
- Flow export: determine whether NetFlow, sFlow or IPFIX is supported, on which gateway/switch version, exporter configuration, collector, permissions, data scope and rate. A flow-record read, `reportFlowEnabled`, DPI or port mirror is not export. Activation needs destination/rate/rollback approval.
- UPS: identify exact 2U Pro/UPS model and firmware; inventory/battery/health reads separately from self-test execution, scheduling, unit cycle and off. Establish confirmation, dry-run with zero controller requests, audit/fail-closed behavior, recovery and service blast radius before a power action. Never live-test power incidentally.
- Standalone: prove `X-API-KEY` works on a specified classic version before designing paths. Compare legacy `/api/s/...`, v2 `/v2/api/...` and Integration `/integration/v1/...` separately with UniFi OS `/proxy/network/...`; record unsupported combinations. Approved read-only probes must be bounded, same-origin, TLS-checked; 401/403 is auth unknown, not endpoint absence; retain unknown if inconclusive. Operator metadata is not auto-detection. Migration and Network 11 live verification are separate work.
- Matter, Thread and Time Machine: recheck https://developer.ui.com/network/v11.0.97/openapi.json (Network 11.0.97 pinned in `scripts/scraped-api-spec-v11.0.97.json`) and version-local Integrations docs on each spec-drift cycle (`DEVELOPMENT_PLAN.md:125-140,619-623`); obtain sanitized UI evidence on approved hardware if public spec remains silent. Reopen only on a published resource or reproducible scoped endpoint with schema, auth and version evidence. Do not fabricate resources or infer support from unrecognized fields.

No controller, capture, flow-export, routing, UPS or migration action is authorized by this record. Mock tests establish only local request/response handling. Independent review and live validation are separate gates.
